# 界面主题与页面样式

本基础版使用白色侧栏、浅灰工作区和低饱和蓝灰强调色。登录页、工作台、菜单、表格、表单保持同一套视觉风格，保留浅色 / 深色切换。

## 常用修改位置

- `frontend/src/store/modules/app.ts`：默认主色、侧栏颜色、标签图标等开关。
- `frontend/src/styles/var.css`：侧栏宽度、顶部高度、标签高度和内容间距。
- `frontend/src/styles/workspace.scss`：公共表格、卡片、菜单与深色外观。
- `frontend/src/views/Login/Login.vue`：登录页排版与文案，复用原有登录组件。
- `frontend/src/views/Home/Index.vue`：工作台入口与指引，入口依据已授权注册的路由显示，不展示虚构业务数据。
- `frontend/src/assets/svgs/workspace-mark.svg`：应用标识；浏览器图标与加载标识使用 `frontend/public/workspace-mark.svg`，替换品牌时同步更新。
- `VITE_APP_TITLE`：应用名称，沿用现有环境配置。

主题缓存使用 `starter-workspace-theme-v1`，避免继承旧版默认颜色。后续在界面设置中调整主题仍可保存。未清理用户登录状态或暗色偏好。

## 检查

开发运行时刷新页面即可查看。构建命令：`pnpm build`。
本次检查覆盖登录页、工作台、用户管理、示例任务列表和新增弹窗；未修改后端接口、权限规则、数据库和部署配置。
