# 标准业务模块：示例任务

> 当前业务目录与分层以 [业务模块开发约定](业务模块开发约定.md) 为准；已新增 V3 命名迁移与 V4 业务入口，新增数据库变更从 V5 起编号。历史 V1/V2 不修改。

登录后进入“开发示例 → 示例任务”。菜单通过 V2 迁移创建，默认授予默认租户管理员；其他角色在角色管理中单独授权。升级后重新登录刷新菜单。

## 可复用结构

| 层 | 路径 | 用途 |
|---|---|---|
| 后端模块 | `backend/cdzs-module-example` | 独立 Maven 模块 |
| Controller / VO | `controller/admin/task` | 接口、参数校验、权限、Excel |
| Service | `service/TaskService.java` | 事务、业务校验、数据访问范围 |
| Mapper / DO | `dal` | MyBatis Plus、租户、逻辑删除 |
| 数据库 | `V2__example_task.sql` | 表、唯一索引、菜单权限 |
| 前端接口 | `frontend/src/api/example/task` | 请求封装 |
| 前端页面 | `frontend/src/views/example/task` | 搜索、分页、表单、导入导出 |

## 已实现的行为

- 编码限定 1–32 位字母、数字、短横线或下划线；名称最多 100 字，备注最多 500 字。
- 状态：0 待办、1 进行中、2 完成；前后端校验并在数据库增加约束。
- 每个租户、每个用户的有效任务编码唯一，重复请求不能重复创建同一编码。
- 逻辑删除后可重复使用编码，包括多次删除、重建。
- 创建人来自服务端登录上下文，前端不能指定 ownerId 或 tenantId。
- 查询、详情、修改、删除、导出统一限制为当前用户的数据；租户拦截器进一步隔离租户。
- 超级管理员也遵循“自己的任务”范围。这是个人任务示例，不是部门数据权限示例。
- 导入最多 1000 行，只新增、不覆盖；格式错误、文件内重复或数据库冲突均整批失败。
- 导出最多 5000 条；超过时提示缩小筛选范围，不默默截断。
- 下载导入模板后填入编码、名称、状态数字和备注，再上传 `.xlsx`。
- 普通请求接入底座 API 访问日志；若项目需要记录字段变更前后值，应额外增加业务操作日志。

## 复制成实际业务

1. 复制模块并改名，例如 `cdzs-module-order`；修改 Java 包名。
2. 在根 `backend/pom.xml` 加 module，在 `cdzs-server/pom.xml` 加依赖。
3. 复制前端 API 和页面，修改接口地址、字段、组件名。
4. 在 `routerHelper.ts` 的页面 glob 加入新模块路径。
5. 新建下一版本迁移，创建业务表和菜单。使用项目预留且不冲突的菜单 ID。
6. 同步修改权限字符串，例如 `order:order:create`，前后端保持一致。
7. 明确访问范围。部门共享数据不能简单删除 owner 条件，需接入部门数据权限规则并测试越权访问。
8. 补充业务测试。不要直接复制示例的错误码段、表名、菜单 ID 到多个模块。

## 验证

本地 Docker 已启动时执行：

```powershell
node scripts/verify-integration.cjs
```

脚本创建独立 MySQL/Redis、随机本地端口，运行真实数据库测试，结束后清理测试容器，不使用根 `.env` 的账号密码。

Jenkins 的对应脚本是 `scripts/ci-integration.sh`，需要 Linux Docker 构建节点，使用容器内 Maven，测试数据库不发布端口。
